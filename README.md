# Minhas Finanças

App de controle financeiro pessoal com visual inspirado no Nubank.

## Funções
- Dia a dia: registrar o que recebe e o que gasta, com nome e valor
- Guardado: guardar e retirar dinheiro, separado do dia a dia
- Quinzenas: finalizar quando quiser e consultar o histórico de recibos

## Como rodar
Abra o `index.html` no navegador. Não precisa instalar nada.

## Dados
Ficam no `localStorage` do navegador (chave `fin_nu_v1`). Limpar os dados do navegador apaga tudo.

## Estrutura
- `index.html` estrutura da página
- `style.css` estilos
- `app.js` lógica e renderização
- `manifest.webmanifest` dados para instalar na tela inicial
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` ícones do app
